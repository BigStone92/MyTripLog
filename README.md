# ✈️ MyTripLog (마이트립로그)

**MyTripLog**는 로컬 맥미니(Mac mini) 홈서버를 백엔드로 활용하며, 비행기 모드나 해외 로밍 오프라인 환경에서도 일정·동선 확인과 가계부 기록이 가능한 **모바일 퍼스트 개인 맞춤형 여행 플래너 PWA**입니다.

---

## ✨ 핵심 기능

1. **📡 오프라인 퍼스트 PWA & 맥미니 자동 동기화**
   - `vite-plugin-pwa`(Service Worker) + 브라우저 네이티브 `IndexedDB`(`mytriplog_idb`)를 통해 오프라인 상태에서도 전체 여행 일정과 가계부를 즉시 조회하고 입력할 수 있습니다.
   - 오프라인에서 추가·수정한 지출 내역과 동선 변경 사항은 `sync_queue`에 보관되었다가 네트워크 복구(`online` / `visibilitychange` / `SyncManager`) 시 맥미니 백엔드(`POST /api/sync`)로 일괄 멱등(Idempotent) 동기화됩니다.
2. **🏠 [홈] 가장 빠른 여행지 맞춤 환율 계산기 & 다가오는 여행 대시보드 (`HomePage`)**
   - **최상단 여행지 맞춤 실시간 양방향 환율 계산기**: 예정·진행 중인 여행 중 가장 출발일이 빠른 여행(`upcomingTrips[0]`)의 목적지·통화(예: `🇻🇳 다낭&호이안` → `VND`)를 자동으로 인식하여 상단에 배치합니다. 현지 통화 ↔ 원화(`KRW`) 양방향 즉시 환산, 단위 칩(`+10,000`, `+50,000` 등), 실시간 환율 API 연동 및 오프라인 로컬 캐시를 지원합니다.
   - 아직 여행 기간이 지나지 않은(`end_date >= 오늘`) 예정·진행 중인 여행 일정 대시보드만 모아 보여주며, 여행 카드를 선택하면 해당 여행의 **일정 상세 화면(`/schedule`)**으로 즉시 진입합니다.
   - **전 세계 249개국 국기 실시간 검색**: 브라우저 표준 `Intl.DisplayNames` 및 도시/국가 별칭(예: `베트남`, `다낭`, `일본`, `스위스`)으로 국기를 즉시 검색·선택할 수 있으며, 국가 선택 시 현지 주 통화(`VND`, `JPY`, `CHF` 등)가 자동으로 매칭됩니다.
   - **한 화면 출발~종료 통합 범위 달력 (`DateRangePicker`)**: 단일 달력 그리드에서 출발일 클릭 후 종료일을 클릭하면 여행 기간(`N박 M일`)이 하이라이트 표시되며, `[일정 확인]` 버튼으로 한 번에 등록됩니다.
3. **📍 [일정 상세] 항공권(가는편/오는편)·숙소·체크리스트·가계부 & 일차별 타임라인 (`SchedulePage`)**
   - 상단 4대 캡슐 버튼(**`+ 항공편`**, **`+ 숙소`**, **`체크리스트`**, **`가계부`**)을 통해 가는편(`🛫`)·오는편(`🛬`) 구간별 항공권/숙소 예약 내역 카드(클릭 시 즉시 수정)와 준비물 체크리스트, 다중 통화 가계부를 한곳에서 관리합니다.
   - `day 1`, `day 2`, `day 3`... 전 일차 세로 타임라인과 각 일차 하단의 **`[ 장소 추가 ]`** / **`[ 메모 추가 ]`** 2열 버튼으로 장소 동선 및 메모를 직관적으로 등록·수정합니다 (여행지 맞춤 명소 프리셋 + OpenStreetMap `Nominatim` 전 세계 실시간 장소 검색).
   - 우측 상단 **`[ 지도 ]`** 토글 시 `@dnd-kit` 드래그 앤 드롭 순서와 연동되는 핀 번호(`1 → 2 → 3`) 및 이동 동선(`Polyline`) 맵이 펼쳐집니다.
4. **💰 [가계부] 다중 통화 지출 기록 (`BudgetPage`)**
   - 25개 주요 여행국 통화 기본 내장, 1,000단위 콤마(`,`) 자동 포맷팅 및 미등록 제3국 통화/환율 직접 추가(`+ 직접 추가`) 기능을 지원합니다.
5. **🌏 [추억] 세계 여행 발자취 지도 & 과거 여행 아카이빙 (`ArchivePage` · `WorldFootprintMap`)**
   - **최상단 세계지도 & 나라·도시 핀 (`WorldFootprintMap`)**: 무료·무키 다크 모드 세계지도(`Leaflet + CartoDB Dark Matter` + 오프라인 벡터 세계지도 폴백) 위에 다녀온 모든 나라·도시 캡슐 핀과 서울/인천(`🇰🇷`)발 **비행 항로 아크(Flight Arc)**를 시각화합니다.
   - **나만의 여행 발자취 통계 배지**: 방문 국가 수, 방문 도시 수, 총 여행 일수, 누적 비행 거리(`km`)를 상단 대시보드로 집계합니다.
   - **개발 이전 과거 여행 간편 등록 & 다중 도시(Multi-City) 태그**: 1990년~현재까지의 `연도·월 간편 선택` 또는 `통합 달력 선택`으로 옛날 여행 기록을 손쉽게 추가할 수 있으며, 한 번의 여행에 여러 도시(예: `오사카 · 교토`, `다낭 · 호이안`)를 동시에 태그할 수 있습니다.
   - **여행 기록 클릭 시 도시 상세 줌인(Fly-To Zoom) & 여행지 이름 표시 토글**: 여행 기록 카드를 클릭하면 상단 세계지도가 해당 여행지의 나라·도시(및 세부 일정 스팟)로 부드럽게 확대되며, 지도 상단 `[이름 켜짐 / 이름 숨김]` 토글 버튼으로 도시명을 숨겨 깔끔한 국기 핀 모드로 전환할 수 있습니다.
6. **🗺️ [지도] 내가 간 곳 여행 색칠 지도 (`ColorMapPage`)**
   - **날짜 & 지역명 입력 시 해당 행정구역 영역(Polygon)만 정밀 색칠**: 날짜와 한글 지역명(예: `강릉시`, `제주도`, `부산 해운대구`, `오사카`, `다낭` 등)을 입력하면 OpenStreetMap 행정경계(`polygon_geojson=1`)를 통해 해당 지역의 테두리 내부만 지도에 색칠(Fill)합니다.
   - **100% 한글 지명 표기 & 여행지 이름 표시 토글**: 외국어 텍스트가 없는 순수 다크 지형 베이스 타일 위에 대한민국 17개 시·도 / 주요 시·군·구 및 전 세계 국가·도시 한글 라벨 레이어를 얹어, 지도의 모든 지역명이 한글로 또렷하게 표시됩니다. 상단 `[이름 켜짐 / 이름 숨김]` 원터치 토글로 색칠 영역 위 배지를 켜고 끌 수 있습니다.
   - **방문 횟수별 농도(히트맵) & 6대 컬러 팔레트**: 동일 지역 다회 방문 시 색칠 채우기 농도가 진해지며, 원하는 테마 컬러를 직접 선택할 수 있습니다.
   - **국내 ↔ 세계 원터치 전환 & 국내 정복률(%) 게이지**: 대한민국 집중 뷰와 세계 지도 뷰를 1초 만에 전환하고 색칠 달성률을 확인합니다.
   - **내 여행 기록 불러와 원클릭 자동 색칠**: [홈]이나 [추억]에 등록된 여행 일정을 한 번에 불러와 지도에 자동 색칠합니다.

## 🛠️ 기술 스택 & 포트 구성

| 구분 | 기술 스택 | 포트 |
| :--- | :--- | :---: |
| **Frontend (PWA)** | React 19, Vite 6, Tailwind CSS v4, Zustand, `@dnd-kit`, `vite-plugin-pwa` | `5174` |
| **Backend (Mac mini)** | FastAPI, Python 표준 `sqlite3` (`WAL` 모드, `backend/mytriplog.db`) | `8050` |

---

## 🚀 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 맥미니 백엔드(8050) + 프론트엔드(5174) 통합 실행
./start.sh

# 또는 개별 실행:
npm run api   # FastAPI + SQLite 서버 (http://127.0.0.1:8050)
npm run dev   # Vite PWA 개발 서버 (http://localhost:5174)
```
